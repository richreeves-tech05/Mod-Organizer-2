## 📖 About

Mod Organizer 2 is an open source mod manager maintained by the Mod Organizer 2 team and the wider modding community. It targets Windows 10 and 11 and supports games such as Skyrim, Skyrim Special Edition, Fallout 3, Fallout New Vegas, Fallout 4 and several others through game plugins. Its core idea is virtual file system based mod isolation: mods are deployed through a virtual layer instead of being copied on top of the game directory, so removing a mod leaves no leftovers behind. The current build adds improved archive handling, updated USVFS hooks, portable instance support and a refreshed plugin API for script extenders and external tools.

If you came looking for a Mod Organizer 2 download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. Everything here is a community reference page: links, notes and setup guidance for the Windows desktop build.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Launcher cannot find the game | Open the game dropdown in the toolbar and pick the correct title, or add it manually. |
| Mods do not appear in game | Check the left pane checkbox for the mod and confirm the profile is active. |
| External tools fail to start | Re run the tool setup from the executables menu and point it at the correct binary. |
| Archive fails to install | Verify the archive is complete and packaged in a supported layout, then retry with the manual installer. |
| Game crashes on load | Run the conflict view, disable the newest mods one by one and rebuild the load order with your sorter. |
| Portable instance not detected | Start the manager with the portable flag or point it at the instance folder from the instance switcher. |
